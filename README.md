# 해피트리 릴스 제작기 V7.1 - 조회수 최적화형

## V7.1 핵심 변화
- 첫 후킹 장면을 2초로 단축
- 전체 길이를 기본 17~20초로 압축
- 녹음·업로드 음원이 있으면 음원 길이에 맞춰 장면 자동 배분
- 말의 분량을 기준으로 장면과 자막 노출 시간 자동 조절
- 자막을 최대 2줄과 안전 영역 안에 표시해 잘림 방지
- 후킹 A/B/C 중 하나를 눌러 영상·음성 대본·표지에 즉시 적용

## V6 핵심 변화
이제 핵심 메시지를 직접 잘 쓸 필요가 없습니다.

### 새 릴스 만들기 순서
1. 프로그램 선택
2. 타깃 선택: 학부모 / 학원장
3. 톤 선택
4. '무엇을 가장 강조할까요?' 선택
5. 후킹 강도 선택
   - 부드럽게
   - 공감 있게
   - 강하게
   - 아주 직설적으로
6. 후킹 10개 자동추천
7. 마음에 드는 문장 하나 선택
8. 선택한 후킹으로 릴스 만들기

선택한 후킹은 자동으로
- 20초 대본 첫 문장
- 화면 자막 첫 장면
- 보이스오버 시작
- 썸네일/인스타 표지 제목
으로 연결됩니다.
